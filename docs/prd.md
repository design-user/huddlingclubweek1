# 웹 초대장 제작 서비스 PRD

## 개요
- 정보만 입력하면 5분 안에 모바일 웹 초대장을 만들고, 링크 하나로 공유해 참석 여부까지 받는 서비스다.
- 로그인 없이 호스트와 게스트 모두 링크로 쓴다.

## 화면 구성과 흐름
- 화면은 세 개다. 호스트는 만들기, 공유, 응답 확인 순으로, 게스트는 보기, 응답 순으로 쓴다.

## 경로
- `/create` : 호스트 — 내용 입력, 미리보기, 발행. 발행하면 초대장 링크와 응답 현황 링크를 보여주고 복사할 수 있다
- `/i/[id]` : 게스트 — 초대장 보기, 이름·참석 여부·동반 인원 제출
- `/i/[id]/responses` : 호스트 — 응답 목록, 참석·불참 수, 참석 인원 합계 확인

## MVP 기능 요구사항
출시에 필요한 기능은 다섯 가지다.
- 만들기 폼 : 제목·일시·장소·본문, 실시간 미리보기
- 발행 : 추측하기 어려운 고유 ID로 초대장 URL 생성, 링크 복사 버튼
- 장소 : 주소를 글자로 표시
- 참석 응답 : 게스트가 이름·참석 여부·동반 인원 입력, 제출 후 완료 화면
- 응답 현황 : 응답 목록, 참석·불참 수, 참석 인원 합계

## 제외 범위
로그인, 결제, 네이티브 앱, 드래그 편집, 축의금 송금, AI 생성, 다국어는 만들지 않는다.

## 내 초대장 (1주차 기획 메모)
- 날짜: 미정 — 1주차 이후 참석자들과 조율 예정
- 주제: 생성형 AI로 디자인하다 '멈춘 순간'을 나누는 모임 — 계속 고칠까, 방법을 바꿀까
- 키워드: 시행착오 공유, 솔직한 분위기, 실패도 기회
