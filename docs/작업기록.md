## 2026-10-11 23:52 — 한국어 주석 스킬(comment-ko) 추가

- **무엇을 바꿨는지:** `.claude/skills/comment-ko/SKILL.md`를 새로 만들었다. 코드 파일 하나를 주면 한국어 설명 주석을 원본 파일에 바로 달아 주는 스킬이다. 파일 맨 위에 요약을 달고, 그 아래로는 핵심 부분에만 주석을 단다. 기존 주석은 그대로 두고 코드는 바꾸지 않는다. 작업이 끝나면 lint를 돌리고 작업기록을 남긴다.
- **왜:** 어려운 코드 파일을 읽을 때 한국어 설명을 바로 보면서 이해하려고.
- **직접 확인하는 방법:**
  1. Claude Code를 새로 시작한다 (스킬 목록을 다시 불러오려고).
  2. `/comment-ko src/app/page.tsx`를 입력한다.
  3. `src/app/page.tsx`에 한국어 주석이 추가됐는지, `git diff src/app/page.tsx`에 주석 줄만 추가됐는지 확인한다.

## 2026-10-11 23:58 — 커밋·푸시 스킬(commit-push) 추가

- **무엇을 바꿨는지:**
  - `.claude/skills/commit-push/SKILL.md`를 새로 만들었다. 다음 순서로 진행한다: 바뀐 파일을 표로 쉽게 설명 → `.env`·키처럼 보이는 값이 있으면 멈춤 → `npm run lint`와 `npm run build` 검사 → `type(scope): 설명` 형식의 한국어 커밋 메시지 제안 → 사용자가 확인하면 확인받은 파일만 커밋하고 현재 브랜치에 push. 강제 push(`--force`)는 절대 쓰지 않는다. `/commit-push`로 직접 부를 때만 동작한다.
  - `AGENTS.md`의 커밋 규칙에 type 종류(feat·fix·style·docs·chore), scope 생략 가능, `/commit-push` 사용을 추가했다.
- **왜:** 비밀 값이 실수로 올라가거나 빌드가 깨진 코드가 push되는 것을 막고, 커밋 과정을 매번 같은 순서로 안전하게 하려고.
- **직접 확인하는 방법:**
  1. Claude Code를 새로 시작한다 (스킬 목록을 다시 불러오려고).
  2. `/commit-push`를 입력한다.
  3. 바뀐 파일 표, 검사 결과, 커밋 메시지 제안이 나온 뒤 "이대로 커밋하고 push할까요?"에서 멈추는지 확인한다. 바로 커밋하고 싶지 않으면 "아니"라고 답하면 된다.
